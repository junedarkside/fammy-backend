# Tech Context

## Technologies Used

- Backend: Django, Python
- Frontend: React, JavaScript
- Database: PostgreSQL
- Message Queue: Celery, Redis
- API Integration: REST APIs

## Development Setup

- Use Docker for containerization.
- Use VSCode for development.
- Use Git for version control.

## Technical Constraints

- Limited budget for infrastructure.
- Need to ensure scalability and performance.

## Dependencies

- Django REST Framework
- React Router
- PostgreSQL adapter for Django

## Tool Usage Patterns

- Use `docker-compose` to manage the development environment.
- Use `manage.py` to run Django commands.
- Use `npm` to manage frontend dependencies.
